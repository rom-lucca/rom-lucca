Transforma uma intenção em trabalho estruturado (**Projeto → Feature → User Story → Subtask → Evidência**),
escolhe os especialistas, coordena a execução e valida tudo de forma independente.
O progresso aparece numa interface inspirada em RPG.

`Python` `uv` `Claude Code` `multi-agentes` · 🔒 repositório privado
</details>

<details>
<summary><b>🛡️ [RARA · concluída] pr-review-kit</b> — gate de pré-revisão de PR</summary>
<br/>

Nenhum PR chega ao humano sem antes passar por convenções, CI e um revisor de IA.
Um hook bloqueia o `git push` de qualquer commit que não tenha aprovação.

`Python` `GitHub Actions` `hooks` · 🔒 repositório privado
</details>

<details>
<summary><b>⚽ [RARA · em andamento] players_classify</b> — dados de jogadores + classificação de estilo por IA</summary>
<br/>

Pipeline que coleta, normaliza e enriquece dados de jogadores (Transfermarkt + Sofascore).
Por cima dele, um módulo de IA classifica a posição real e o estilo de jogo.

`Python` `httpx` `BeautifulSoup` `SQLite` · 🔒 repositório privado
</details>

`Python` `APIs REST` `Jupyter` · 🔒 repositório privado
